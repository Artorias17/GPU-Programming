Based on google search and AI explanation of the last ptxax info
The kernel uses 31 registers per thread, 2048 bytes of shared memory and 392 bytes of constant memory.

Since our block size 16x16 = 256 threads per block

V100 Specs
Number of SMs: 80
Registers per SM: 65536
Max blocks per SM: 32
Max threads per block: 1024
Max threads per SM: 2048

So, maximum blocks allowed based on the kernel block size = 2048 / 256 = 8 blocks.
Simultaneous threads per SM = 8 * 256 = 2048 threads.
Simultaneous register usage per SM = 2048 * 31 =  63488 registers.

Simultaneous threads per V100 = 2048 * 80 = 163840 threads

Thus, the kernel has full occupancy with V100, totalling 163840 simultaneous thread usage.
