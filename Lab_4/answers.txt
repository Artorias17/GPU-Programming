We can define FLOPS as Total Floating-Point Operations / Kernel Execution Time
Now, for the convolution with 5x5 filter matrix,
the operations are as follows:
An entry in the output Matrix = 25 multiplications + 25 summation (With the initial 0) = 50 operations
So,
for a 10x10 Matrix =  10 x 10 x 50 = 5000 operations = 5000 / 0.004237 = 1,180,080.25 FLOPS
for a 100x100 Matrix = 100 x 100 x 50 =  500000 / 0.004811 = 103,954,262.11 FLOPS
for a 1000x1000 Matrix = 1000 x 1000 x 50 = 50000000 operations = 50000000 / 0.005438 = 9,193,717,325.11 FLOPS


For a 100x increase in Matrix entry, kernel time increases by 13% and FLOPS increase by 88x.
